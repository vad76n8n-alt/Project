# Учебное задание — страница «Проекты»

Демонстрационный frontend-прототип без сервера и без реальных данных.

## Сделано
- список проектов;
- поиск по названию и описанию;
- кнопка «Создать проект»;
- форма создания проекта;
- валидация обязательного названия;
- сохранение проектов в localStorage после обновления страницы;
- адаптивная верстка: на телефоне поиск и кнопка не перекрываются;
- только тестовые данные.

## Запуск
Откройте `index.html` в современном браузере. Интернет и backend не требуются.

## Проверка
1. Открыть страницу.
2. Проверить поиск.
3. Создать тестовый проект.
4. Обновить страницу — проект должен сохраниться.
5. Проверить узкое окно/телефон — элементы панели не должны перекрываться.

## Ограничения
Учебный frontend-прототип. Авторизация, серверная БД и реальный API намеренно не используются.
